## EPG (节目单)

```
https://epg.112114.xyz/pp.xml.gz
```

Preferred source, ~220 KB gzip and reliable; the playlist header already advertises it via `x-tvg-url`.

`live.fanmingming.com` is currently unreachable; its EPG lives on GitHub — use `https://gh-proxy.org/raw.githubusercontent.com/fanmingming/live/main/e.xml` (7.8 MB) if you want its extra coverage. Neither source covers the specialty channels (CHC, SiTV, 4K…), which carry no EPG data anywhere.

All m3u `tvg-logo` URLs use a working host (`epg.112114.xyz` or the fanmingming GitHub mirror). After swapping the EPG URL in your player, reload the playlist/EPG (TiviMate: *Settings → Playlists → [list] → OK*; Kodi: *Settings → PVR & Live TV → Guide → Clear cache*) — the guide repopulates within a minute.

## Reachability check

```
python3 scan.py
```

Tests every stream URL in `shaanxi-mobile-cdn.m3u` and `shaanxi-mobile-xian-gitv.m3u`, classifies them as `reachable` (HTTP 200 anywhere), `intranet` (CMCC IP blocks — may or may not play depending on the operator), or `dead`, and writes `scan-results.csv`. Useful as a periodic audit; the heuristics live in `scan.py` (`CMCC_NETS`, `KNOWN_INTRANET_HOSTS`, `TIMEOUT_S`).

## Point-in-time replay (回看) for the CDN list

The CDN server keeps **7 days** of every channel. Two ways to watch a past moment:

**1. Manual URL** — for any `PLTV/…/index.m3u8` link, change `PLTV` → `TVOD` and append a time window:

```
.../TVTV.../index.m3u8?playseek=20260925200000-20260925203000
```

Plays the 20:00–20:30 segment of that day (format: `yyyyMMddHHmmss-yyyyMMddHHmmss`, Beijing time).

**2. Guide-based replay in a player** — regenerate the catch-up playlists:

```
python3 merge.py         # fold raw/lingbaoboy-tv2.m3u into the base list (priority)
python3 scan.py          # audit reachability → scan-results.csv
python3 prune.py         # remove entries not marked 'reachable'
python3 make-catchup.py  # write the two catch-up variants
```

`make-catchup.py` rewrites every CMCC `PLTV` channel's `#EXTINF` with `catchup="default"`, a `catchup-source` pointing at the TVOD endpoint, and `tvg-rec="7"`. Load the generated file *together with the EPG above* (the player needs programme start/end times to fill in the window), then open the guide, scroll back, and pick any past programme.

> Pruning removes channels that fail from off-net (CMCC edge-node 404s, intranet-only IPs). On China Mobile home broadband you may be able to keep more — comment out the `prune.py` step or hand-pick from `scan-results.csv`.

- `shaanxi-mobile-cdn-catchup.m3u` — `${(b)yyyyMMddHHmmss}-${(e)yyyyMMddHHmmss}` template: TiviMate, DIYP/百川, APTV, TVBox-family players. In TiviMate, if no replay icon shows in the guide check *Settings → Playlists → [list] → Catch-up*.
- `shaanxi-mobile-cdn-catchup-kodi.m3u` — `{utc:YmdHMS}-${end:YmdHMS}` template for Kodi's PVR IPTV Simple Client. In the add-on settings set *Catchup → Enable catchup*.

Keep the device clock/timezone set to Beijing time (UTC+8), or replay windows will be offset.

Segments are served from CMCC CDN edge nodes — test playback on a China Mobile (Shaanxi) connection; off-net requests 404 at the edge.

## True multicast (rtp://组播)

The unicast lists above are the practical choice. Real multicast (`rtp://239.x.x.x`) requires the IPTV VLAN on your光猫 + `udpxy`/`msd_lite` on an OpenWrt router — see SPX372928/MyIPTV and wcb1969/iptv on GitHub for Shaanxi multicast addresses.
